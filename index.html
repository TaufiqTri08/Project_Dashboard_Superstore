Alternatif: Jalankan Server Lokal

Agar browser dapat memuat data secara otomatis tanpa perlu mengunggah file secara manual, jalankan perintah server lokal di folder workspace ini:

npx live-server

Kemudian buka alamat yang ditampilkan (biasanya http://127.0.0.1:8080) pada browser Anda.
